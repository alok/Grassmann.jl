# GrassmannGallery

The plot gallery of the chakravala ecosystem, rebuilt with the Lean port and
[LeanPlot](https://github.com/alok/LeanPlot), side by side with the Julia/CairoMakie originals:
[`docs/gallery/index.md`](../docs/gallery/index.md).

This is a Lake package of its own: it requires the root package (`path = ".."`) and LeanPlot
(pinned to `f141f59`, by full hash), so the root package keeps zero dependencies.

```
lake exe gallery                 # render out/<name>.png and out/<name>.svg, compare with the Julia data
lake exe gallery --only fatou    # a subset, by name prefix
lake exe gallery --docs          # also copy the PNGs to docs/gallery/lean/ and regenerate the index
lake test                        # the data checks alone (Gallery.Check.run)
```

The Julia side lives in `oracle/gallery/`: one script per figure renders
`docs/gallery/julia/<name>.png` and dumps the plotted data to `oracle/gallery/data/<name>.json`
(`julia --startup-file=no --project=oracle oracle/gallery/run_all.jl [prefix …]`).

| module | contents |
|---|---|
| `Gallery.Common` | `Entry`/`Check`/`Outcome`, JSON accessors, comparison helpers |
| `Gallery.Fatou` | Fatou.jl README and wiki: cobweb orbit, filled Julia sets, Mandelbrot, Newton fractals |
| `Gallery.Versor` | Julia's `exp` of even elements, Riemann-sphere and conformal `↑`/`↓` |
| `Gallery.Grassmann.*` | Grassmann.jl README and paper: plane fields, conformal curves, 3D streamplots, graphs |
| `Gallery.Wilkinson` | Wilkinson.jl `plot(::PolynomialComparison)` |
| `Gallery.ImageDiff` | pixel agreement of the Lean and Julia PNGs |
| `Gallery.Index` | `docs/gallery/index.md` and the list of figures waiting for Cartan/Adapode |
| `Gallery.Check`, `Gallery.Test` | the `lake test` driver: every figure's data checks and README spot values |
| `Gallery.ColormapData` | Makie colormaps LeanPlot does not ship (generated by `oracle/gallery/colormaps.jl`) |
