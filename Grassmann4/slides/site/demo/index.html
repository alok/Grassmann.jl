instance instHMulMV :
    HMul (MV sig p1) (MV sig p2)

  hMul := mulDirect

Signature 3 carries the metric. Parity records which grades may occur. DataArray is Lean’s contiguous FloatArray. Thus MV R3 .full stores 8 coefficients; MV R3 .even stores 4.
